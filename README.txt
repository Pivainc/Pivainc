PUBLISH ON GITHUB PAGES
1. Extract this ZIP on your phone/computer.
2. Open your GitHub repository and choose Add file > Upload files.
3. Upload the four files above into the repository root (not a nested folder).
4. Commit the changes.
5. In Settings > Pages, select Deploy from a branch, branch main, folder /(root), then Save.
6. Wait a few minutes and open the Pages URL shown by GitHub.
